# Учебная программа Python Fullstack + AI

Этот каталог — учебная часть репозитория [lesson](https://github.com/mars485/lesson). Обучение идёт от основ Python до fullstack-разработки с React, FastAPI, Django и AI API.

**Основа:** программа «Разработка web-проектов на Python» (предоставленный учебный план, 2025). Здесь сохранены восемь тематических модулей, но сроки адаптированы под персональный график. **Это не эквивалент заявленных в исходной программе 736 академических часов**: короткие занятия необходимо дополнять самостоятельной практикой.

**Практический проект:** [ai-prompt-service](https://github.com/mars485/ai-prompt-service). Упражнения здесь выполняются в отдельной учебной среде: рабочий MVP изменяется только отдельными осмысленными PR/коммитами после проверки.

## Режим обучения

- 52 недели, ориентир — 156 коротких занятий, три в неделю по 45 минут.
- Основные дни — выходной и отсыпной по циклу «день → ночь → отсыпной → выходной». При необходимости третий урок — в свободный период другой смены.
- Каждое занятие (45 минут): **10 минут — теория → 10 минут — разбор примера → 20 минут — самостоятельная практика → 5 минут — самопроверка и фиксация результата**.
- По завершении недели: отметить прогресс в [PROGRESS.md](PROGRESS.md); при необходимости добавить самостоятельную практику.

## Как устроены материалы

- В каждом модуле есть README с целями, темами и проектным результатом.
- Для каждого практического занятия используем одинаковую схему: `README.md` (теория и условия), `exercise.py` (стартовый код), при необходимости `tests/` и `notes.md`.
- Начальная точка: [занятие 01 — переменные](01-python-basics/lesson-01/README.md).
- [Шаблон занятия](templates/LESSON_TEMPLATE.md) и [трекер](PROGRESS.md).

## Подготовка

1. Установить Python 3.12+ и VS Code.
2. Клонировать: `git clone https://github.com/mars485/lesson.git`.
3. Перейти в `course/01-python-basics/lesson-01/`.
4. Выполнить `python exercise.py` (на некоторых системах `python3`).
5. После самостоятельного решения сделать коммит, например: `git add course/ && git commit -m "learn: complete python lesson 01"`.

⚠️ Не сохраняй в репозитории реальные API-ключи, пароли, `.env`, виртуальные окружения и персональные данные. Для будущих интеграций используем `.env.example` с пустыми значениями.

## Правила готовности

Занятие считается пройденным, если пример запускается, практическая задача работает по критерию из README и учащийся может словами объяснить ключевое понятие. Более крупные самостоятельные проекты могут потребовать дополнительного времени.
