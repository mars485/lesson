# 01 — Основы Python
**Недели:** 1–8 · **Занятия:** 24

**Цель:** уверенно читать и писать простые программы, применять переменные, структуры данных, функции и основы ООП. Знакомство с генераторами, декораторами и pytest — без ожидания профессионального уровня после восьми недель.

| Неделя | Занятие 1 | Занятие 2 | Занятие 3 |
|---|---|---|---|
| 1 | Переменные | Типы данных и строки | Практика: параметры промпта |
| 2 | Условия | Сравнения и логические операторы | Проверка пользовательского ввода |
| 3 | Списки | Словари и циклы | Каталог шаблонов промптов |
| 4 | Функции | Аргументы и return | Функция генерации промпта |
| 5 | Работа со строками | JSON и CSV | Сохранение шаблонов |
| 6 | Классы и объекты | Инкапсуляция и наследование | Класс PromptTemplate |
| 7 | Итераторы и генераторы | Декораторы | Переиспользуемые помощники |
| 8 | Аннотации и docstrings | Pytest и pydocstyle | Мини-проект и разбор |

**Мини-проект:** консольная программа, принимающая тему, аудиторию, тон и сохраняющая шаблоны в JSON. Каждая новая функция покрывается простым тестом.
