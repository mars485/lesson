# Урок 01 — переменные в Python

**Модуль:** [Основы Python](../README.md) · **Продолжительность:** 10–15 минут

## Цель
Научиться сохранять тему и аудиторию в переменных и составлять на их основе промпт.

## Понятие
Переменная — понятное имя для значения, которое программа может использовать повторно. В Python присваивание записывается через `=`.

## Пример

```python
topic = "Разработка сайтов"
audience = "Предприниматели"
prompt = f"Напиши статью на тему: {topic}. Аудитория: {audience}."
print(prompt)
```

В строке `f"..."` подставляются значения, указанные внутри фигурных скобок.
